## Overview

I turn messy data into clean, usable output — and I do it fast.

Most of my work falls into three buckets:

**Parsing and extraction.** Odd log formats, inconsistent exports, PDFs and scraped pages that don't sit neatly in rows.
I've built parsers and type-checkers from scratch, so the file that "can't be automated" usually can.

**Automation and cleaning.** Python scripts that take a repetitive manual process and make it one command.
Deduplication, validation, reformatting, scheduled reports.

**Small, fast web pages.** Hand-written HTML/CSS/JS with no framework and no build step — loads instantly, works
offline, nothing to maintain and no monthly platform fees.

I also build language tooling: I designed and implemented a programming language across seven runtimes (C, C++, Python,
Ruby, Java, SQL, JavaScript), including the parser, type checker and interpreter. That's why unusual parsing and
data-correctness problems tend to be straightforward for me.

One thing I care about more than most: **silent wrong answers**. A missing value that quietly becomes zero will produce
a number that looks fine and isn't. I check for that by default.

Happy to start with a small paid test task so you can see how I work before committing to anything larger.
