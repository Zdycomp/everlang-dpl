Depth is
earned.

A recursive function does not get to go deep because you trust it. It goes deep when it has proved it will stop. That one rule, followed honestly for eight layers, ends up as a tool that fixes Gradle builds.

A function can sit at 217 and still loop forever.

A wrong termination proof is worse than no proof.

The instrument

Every value carries how much it is trusted.

Most languages give a value two states: it exists, or it is null. This one gives it a scale — and one state that is not on the scale at all.

0 · Zunknown, with its reason
128execute floor
256Certain

Why 256

4⁴ — the states of a byte. Every other constant is derived from it, not chosen: the floor is 256/2, the enumerate threshold ⌊256/π²⌋ = 25, the emulate ceiling ⌊π⌋ = 3.

Z is not a low number

It is its own state, it carries the reason it is unknown, and it is contagious. Anything touching Z becomes Z. Confidence flows down, never up.

Certain is earned

256 comes from verification at runtime. Static inspection deliberately cannot reach it, and — see below — no stack of evidence can either.

Then the contagion turned out to be arithmetic.

Let u = (256 − confidence) / 256 — normalized ignorance. Corroboration between two independent witnesses is identically u_result = u_a × u_b: the standard rule for combining evidence, checked exactly across the full grid at 1089/1089. Three consequences nobody designed in:

  • to manufacture confidence Two witnesses agreeing multiplies two ignorances into a smaller one. The confidence was already distributed across them; corroboration only revealed it.
  • to treat Z-contagion as a rule Z has u = 1, and 1 × x = 1. Z absorbs because it is the absorbing element under multiplication. It was written in as a design decision; it is a theorem.
  • to reach Certain by combination u = 0 requires some u_i = 0 exactly, and a product of non-zero terms is never zero. No stack of imperfect witnesses, at any strength or count, gets there.

That third one exposed a live bug. The integer scale had been rounding the last fraction away, so excel(250, 250) returned 256 — the language inferring Certain from accumulated evidence, in direct contradiction of its own rule. True value: 255.78. Fixed in C, Python and Ruby; combination now caps at 255.

The Zeroth Law

Before you can combine two readings, they have to be readings of the same thing.

The First Law says what happens when evidence combines. The Zeroth says confidence is a comparable quantity at all — and it is numbered first because everything above it had quietly assumed it.

If two threads are each in equilibrium with a third, they are in equilibrium with each other.

The law

Thermodynamics named this one last and numbered it first for exactly the same reason. Without transitive equilibrium, two thermometers can each agree with a third and disagree with each other — and then temperature is not a property of anything, just a reading on a particular instrument.

The stack had that hole

Six layers compared confidence to confidence. The only predicate for it, written identically in C++ and Java, was proximity:

1-phase-cpp/phase.cpp — beforemeasured
std::abs(a.confidence - b.confidence) < E_PI_WIDTH_WARN   // < 81

  |0 - 1|   =  1   < 81   ✓
  |1 - 81|  = 80   < 81   ✓
  |0 - 81|  = 81   < 81   ✗   the chain breaks

  969,840 of 4,922,897 candidate triples break it — 19.7%

Reflexive and symmetric, and not transitive. That is a tolerance relation, and no tolerance relation is transitive — so widening the threshold does not fix it. A predicate that cannot be chained cannot license a scale.

There was a quieter finding underneath. Proximity had exactly one caller, a.confidence == b.confidence && sameSpectrum(a, b) — and equal confidences have a gap of zero, which is inside any width. The system's only comparison predicate was both non-transitive and inert at its only call site.

The fix is structural, not numeric

Equilibrium is now equality of band, and band is a total function of confidence. That single fact is the entire proof: a ~ b ⟺ f(a) = f(b) is the kernel of a function, and the kernel of a function is an equivalence relation by construction — not by luck, and not by testing. So the thing to protect is the totality of band, which is what every layer's test checks.

And it travels exactly as far as an anchor does

An unanchored thread pays one confidence per language crossing. One point is nothing — unless the thread is standing on the floor of its band.

Two threads comparable at home are not comparable abroad — and nothing in the old code could have noticed, because the old predicate had no notion of a boundary to cross.

Depth is earned. So is comparability.

The Zeroth Law survives assimilation exactly for anchored threads

Which is the sentence this whole page has been saying at every scale. fact earns unbounded depth with three Examples and a decreasing measure. A fixture earns rulehood with three distinct sources and a clean replay. A thread earns the right to mean the same thing in another language by being anchored.

One law, or four opinions

The law is stated in C, C++, Python, SQL and Java. Stating it five times is only worth anything if they can be checked against each other — a law five layers each hold privately is five laws.

Agreement — one law, or four opinions
  ✓ Python and C agree on all 257 values
  ✓ Python and SQL agree on all 257 values
  ✓ Python and Java agree on all 257 values
  ✓ all of Python, C, SQL, Java agree on every boundary

Only one layer can refuse. Everywhere else the law is a predicate a caller may forget to consult; in the archive it is a constraint at the storage boundary — an anchored crossing that changed band is rejected, and the table that defines the bands is closed to editing, because moving one boundary to overlap its neighbour would silently destroy transitivity in every view above it.

An unanchored crossing that changes band is allowed, and lands in v_band_drift naming both bands. Drift that is recorded is the design. Drift that is silent is the failure.

Five compile targets

Go, Rust, R, Kotlin, JavaScript — each matched to the reference value-for-value and confidence-for-confidence. This host has only a JS toolchain, so 12 cases re-verified here and four targets reported SKIP. The other four are the project's own prior result, not something this page re-ran.

Foreign code is capped at 120

Calling real libm through FFI — sqrt, pow, sin — works, and lands at 120/256, because the language cannot audit what foreign code did.

The same discipline runs a real 1D logistic regression by gradient descent, checked bit-for-bit against an independent from-scratch implementation. Make one training label z and the trained weight correctly comes back unknown — not a number quietly learned from the labels that happened to be there.

Layer 3 · Ruby  —  Layer 6 · hand HTML

An instrument you cannot inspect is not an instrument. It is a claim.

So Layer 6 is hand-written HTML — no framework, no CDN, no build step — and it was pointed at itself.

It came back Z, with five errors. Four were false positives: the inspector was reading <script> string literals as markup. A false positive that reaches Z is worse than a missed finding, because it teaches the corpus something untrue — both layers were fixed to strip script, style and comment bodies first.

The fifth was real and would have broken the page in a browser: a bare </script> inside a JavaScript string terminates the script element regardless of string context. Then the cross-layer check found a bare C function with no #include being detected as Ever by both layers — consistent, and wrong.

238 self-inspection

After the fixes, Layer 6 inspects itself at 238/256, zero errors. The system found three real defects in its own source. That is the thesis demonstrated on itself rather than asserted.

Cross-layer agreement — Python and the browser producing identical particles for identical input — holds at 11/11.

Layer 4 · SQL

The archive refuses to store a contradiction.

Not application checks a careless caller can skip — triggers, at the storage boundary.

  • a Z particle carrying confidenceZ has no degree. If it had one it would be low confidence, which is a different state.
  • a Certain particle at anything but 256Certain is exact or it is not Certain.
  • an Emulate past ⌊π⌋ = 3Borrowed patterns decay. Past three errors of distance the honest answer is Z.
  • DELETE, on anythingNothing is discarded. An EError is a boundary marker: it records where the edge of the known sat that day.

Why a database and not a log file: E = MC² — Mental creation, Masterful correlation, and C² is the archive correlating its own correlations. That is a join, not a loop. It has to be able to ask questions about itself.

Layer 7 · Node  —  ReFix

The same gate, seven layers later.

ReFix matches Gradle build errors against a signature corpus and archives every accepted repair as a (Failure, Fixture) pair. It proposes a new rule only when that fixture has earned it.

What fact had to do

Pass three Examples. Then prove a decreasing measure. Then it may recurse without a ceiling.

What a fixture has to do

Recur across three distinct sources. Then replay against the entire archive without changing one prior outcome. Then it may become a rule.

Distinct sources, not distinct rows. Ten repairs in one repository is one habit, not a rule — the threshold exists precisely so that the evidence comes from people who were not talking to each other. It is the corroboration law from Layer 0, applied to build logs.

128Admitted
ZRejected · kept

A rule is born at intake — 120, deliberately below the execute floor — and rises to 128 only by surviving replay. It does not rise further from replay alone; further evidence is real usage. And a rejected rule is preserved forever with its reason, because knowing which generalisations failed is the part of a corpus that is expensive to rebuild.

The other half of the claim

What this is not.

  • to be a general program synthesiserThe synthesis grammar is bounded and stated: arithmetic to depth 2, single recursion. What it cannot reach is therefore stated too.
  • to prove correctnessundermine finds counterexamples. When it finds none it returns Z, because no counterexample found is not a proof and must not be dressed as one.
  • to improve without boundThe evolution loop converges and reports convergence — “incumbent held; no improvement found” — rather than churning to look busy.
  • to be governed by φ1 of 6 corpus ratios lands near 1.618, which is what chance would give. φ earns its place as the output equalizer, applied deliberately. Claiming more would be decoration.
  • to be firstSQL’s NULL and floating-point NaN do the mechanically same thing; Uncertain<T> and Julia’s Measurements.jl do it with real statistical rigor. This trades that rigor for a number anyone can read at a glance — then takes it into recursion depth, foreign calls, and training loops.
  • to be production-readyFor anything that is not a demonstration.

And the merge that produced this repository found six defects by running it rather than reading it. Five were the same class — extent not delimited: a stray comment opener, a trailing slash, a docstring delimiter written with two quotes instead of three. The corpus’s own research had already named that class as 84.2% of all findings and the highest-value one to target. It was also 100% of what had rotted.
