The rules this instrument enforces
  1. Z is zero-absolute

    Unknown is not low confidence. It is its own state, and it carries the reason it is unknown.

  2. Z is contagious

    Anything touching Z becomes Z. Confidence flows down, never up. Enforced in C, at the atom, so no layer above can launder an unknown into a fact.

  3. π governs width

    A range wider than ⌊256/π²⌋ = 25 must be enumerated. Wider than ⌊256/π⌋ = 81 and it is effectively unknown.

  4. Certain is earned, never guessed

    Static inspection cannot reach 256. Reading code tells you it is well formed, not that it works.

  5. Emulate stops at ⌊π⌋ = 3

    Past three errors from working, borrowing a neighbour's pattern is guessing. It returns to Z and gets fixed properly.

  6. Nothing is discarded

    A failure is archived as a boundary marker. It records where the edge of the known sat that day.
